## 📌 Project Overview

ShopSphere is a responsive e-commerce web application that allows users to browse products, search for products, filter products by category, view product details, and add products to a shopping cart.

The project demonstrates frontend development, API integration, responsive UI design, JavaScript ES6 modules, browser LocalStorage, GitHub version control, and deployment-ready project architecture.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🛍️ Product Catalog
- 🔍 Product Search
- 📂 Category Filtering
- 📦 Product Details Page
- 🛒 Add Products to Cart
- ❌ Remove Products from Cart
- 💰 Automatic Total Price Calculation
- 🔢 Cart Item Count
- 💾 LocalStorage Cart Persistence
- 📱 Responsive Mobile Design
- 🔗 Hash-Based Navigation
- 🌐 Dynamic API Integration
- ⚡ Error Handling
- 🚀 Deployment-Ready Structure
